- Shell Script :Shell Script is a set of commands written in sequence from top to bottom.

- shebang (#!/bin/bash) :It is the absolute first line of a Linux Shell Script.It acts as an Instruction manual for OS ,telling Linux
exactly which program to use to read and execute the code inside in the file.

- What happens if you remove the shebang line?
Removing the shebang line (#!) from a script means the operating system's kernel does not know which program or interpreter should run
the file.
